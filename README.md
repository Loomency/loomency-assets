# Loomency Cloud Public Assets

This repository contains publicly accessible branding assets for Loomency Cloud.

## Assets

- `assets/branding/logo-black.png` - Logo for light mode
- `assets/branding/logo-white.png` - Logo for dark mode

## Usage

These assets are publicly accessible via GitHub raw URLs:

- Light mode: `https://raw.githubusercontent.com/Loomency/loomency-assets/main/assets/branding/loomency-logo-black.png`
- Dark mode: `https://raw.githubusercontent.com/Loomency/loomency-assets/main/assets/branding/loomency-logo-white.png`
